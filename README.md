RESTful API desenvolvida em Python para gerenciamento de dados, servindo como a camada de backend para uma futura aplicação Web Full Stack. O projeto abrange a criação de rotas, manipulação de banco de dados e regras de negócio.

---

## 📌 Visão Geral do Projeto

Este repositório faz parte da primeira fase do desenvolvimento da aplicação. O foco atual é construir uma base backend sólida, segura e escalável, que posteriormente será consumida por uma interface em **React**.

### 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python
- **Framework Web:** FastAPI / Flask *(ajuste para o seu framework)*
- **Banco de Dados:** SQLite / PostgreSQL *(ajuste conforme o seu banco)*
- **ORM / Query Builder:** SQLAlchemy / Peewee *(remover se não utilizar)*
- **Versionamento:** Git e GitHub
